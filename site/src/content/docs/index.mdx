share-claude は、各プロジェクトへ Claude Code の設定（スキル・hooks・禁止/許可ルールなど）を配るためのリポジトリです。このサイトでは、各プロジェクトに何が配られているかを確認できます。

## サイトの見方

左のサイドバーからプロジェクトを開いてください。プロジェクトごとに次のページがあります。

- 概要: そのプロジェクトで使えるスキルの一覧
- スキルごとのページ: 呼び方と、できること
- 自動で動くもの: hooks（ツール実行の前後で自動実行されるもの）
- 禁止・許可: Claude が実行を禁止されている / 確認が必要 / 確認なしで実行できる操作

すべてのプロジェクトに入る設定だけを見たいときは、サイドバーの「共通」を開いてください。プロジェクトのページにも共通の設定は含まれていて、共通スキルの行は共通側のページにつながっています。

## スキルの呼び方

Claude Code のチャットで `/スキル名 引数` と入力して呼び出します。スキルによっては、スキル名の後ろに引数（例: `[番号]`）を付けられます。引数の形は各スキルのページに書いてあります。

「手動のみ」と書かれたスキルは、Claude が自動では使いません。自分で `/スキル名` と入力したときだけ動きます。

## 「共通」と「専用」

- 共通: すべてのプロジェクトに配られる設定（`common/` 由来）
- 専用: そのプロジェクトだけに配られる設定（`project/<名前>/` 由来）

## 設定を追加・変更するには

設定は [share-claude リポジトリ](https://github.com/j0811s/share-claude)で管理しています。追加や変更は、このリポジトリへの Pull Request で行ってください。このサイトは、リポジトリの内容から自動で生成されます。
